# IAM Conviction

## Project Overview

Steps and proof of expertise in the field of Identity and Access Management.

## Business Scenario

Company ZeroSec had a requirement to setup organization Identity provider (IDP) Microsoft Entra and manage user access within it.

## Tools Used

- Microsoft Entra ID

## What I Built

Provisioned Tenant and mapped users to policies following the principle of least privilege. Goal was to allow seamless access for JML (joiner, mover, leaver) while hardening security visibility.
